在 LottiePlayer 已有事件监听的基础上，新增帧级书签（Bookmark）系统：用户可在任意播放头位置添加命名书签并附可选备注，导航面板列出当前动画全部书签，点击跳转并 seek 到精确帧；书签与 src 一起持久化在动画 JSON 内的 __bookmarks 字段里，外部 JSON 文件加载时不能丢失本地新加的书签（合并而非覆盖）；书签重名时按创建时间排后面，删除最后一个书签后导航面板自动隐藏。在 Controls 控件基础上扩展为可拖拽悬浮工具栏：默认吸在播放器右下角，用户按住头部可拖到四角任意位置并记住位置（同一 src 下回访保留），拖出播放器视口边界时回弹到最近角落；拖动期间控件按钮不响应点击避免误触，松手后再启用。在 Popover 弹层基础上新增导出当前帧为 PNG 的能力：弹层里点"导出帧"按钮抓取当前渲染像素（按 lottie-web renderer 实际渲染源 svg 或 canvas 分别处理），生成 dataURL 触发浏览器下载，文件名格式 <animation-name>-frame-<frame-number>.png；导出过程播放器保持运行不暂停，导出失败（比如无 src、跨域资源或 CORS 拒绝）时弹层内显示错误而不阻塞 UI。检查修复一下。
